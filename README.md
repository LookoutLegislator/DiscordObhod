> ### Реакция антивирусов
> WinDivert иногда определяется антивирусами.  
> Это инструмент перехвата и фильтрации сетевого трафика, без которого zapret не сможет работать.
> Один и тот же инструмент могут использовать как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит файлы WinDivert к потенциально опасным или хакерским инструментам. В результате файл удаляется и отправляется в карантин. Такое обнаружение обычно имеет название `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса или отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, лучше добавить необходимое исключение. В противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Установка и запуск

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите пункт "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox откройте настройку "DNS через HTTPS", выберите режим "Персональный", затем нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, можно использовать `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в параметрах системы — [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется
    * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/LookoutLegislator/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`
    * Для автоматического запуска перейдите в **`service.bat`**: `Install Service` -> *выберите подходящую стратегию*

## ℹ️Назначение файлов и пунктов меню

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для себя**

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные инструменты:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — включить или отключить обход для игр и других приложений, использующих UDP и TCP-порты выше 1023.  
  **После смены этого параметра стратегию нужно перезапустить.**  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** — изменить режим обработки ресурсов из `ipset-all.txt`.  
  Этот пункт полезен при проверке ресурса, который без zapret работает, а с ним перестаёт открываться.  
  В скобках показывается выбранный режим:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP проверяется на наличие в списке
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить используемый фейк другим файлом из каталога `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном прекращении работы приложения
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — проверить сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` нет видимого результата

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/LookoutLegislator/zapret-discord-youtube/issues/522)

### Не удалось подобрать ни одной стратегии
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts-файл устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося Блокнота
  - Найдите файл `hosts` в созданной папке и откройте его текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените аналогичные строки, если вы уже добавляли их раньше
  - Сохраните файл и проверьте подключение. Если проблема осталась, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. Если этот способ не помог, используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/LookoutLegislator/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии не гарантируют постоянную работоспособность.**
> Конкретный вариант может некоторое время работать, а затем перестать обходить блокировку после обнаружения используемой схемы.
> В репозитории собрано много стратегий. Если ни одна не подходит, создайте новую на основе одной из существующих и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`

- Убедитесь, что нужный адрес присутствует в списке доменов или IP-адресов

- Проверьте другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/LookoutLegislator/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить программу?
- Сохраните добавленные вами ресурсы и другие нужные данные
- Перезагрузите устройство
- В `service.bat` выберите `Remove Services`
- Затем откройте `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце нажмите Y
- Удалите каталог zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/LookoutLegislator/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть пункт разблокировки, включите его, нажмите «Применить» и «ОК»
- Распакуйте архив в новый каталог в корне диска, исключив пробелы и специальные символы из пути
- Запускайте разные скрипты `general` и проверяйте доступность ресурсов. Если интернет-ресурсы не открываются, завершите программу через значок замка на панели задач и выберите другую стратегию
- После нахождения рабочего варианта установите его в автозапуске: `service.bat` -> `Install Service` -> выберите нужную стратегию

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о проблеме с WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### В Windows 7 требуется цифровая подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) версиями с теми же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё числится среди служб

1. Узнайте имя службы в командной строке Windows. Откройте Win+R, введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться
- Переберите остальные стратегии, особенно если ранее всё работало
- См. также [#251](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS включён](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить именно её
- В `service.bat` перейдите в `Run Diagnostics` и очистите там кэш Discord
- Проверьте, заработало ли приложение после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, её можно использовать
- Если Discord не открывается и в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Используйте [tg-ws-proxy](https://github.com/LookoutLegislator/tg-ws-proxy)
- Либо подключитесь к бесплатным MTProto-прокси, доступным в интернете

### Не запускаются игры

Игры используют разные сетевые схемы, поэтому проверить и исправить каждую из них невозможно.

Попробуйте следующий общий порядок действий:
- через `service.bat` обновите ipset и включите `Game Filter`
- если результата нет, дополнительно включите `ipset any`

Учтите, что режим `ipset any` может нарушить открытие большого количества сайтов. Не оставляйте его включённым постоянно. Вместо этого определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если это не помогло, создайте обсуждение в разделе [Discussions](https://github.com/LookoutLegislator/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Моей проблемы нет в списке

- Опишите её [здесь](https://github.com/LookoutLegislator/zapret-discord-youtube/issues)

## 🗒️Как добавить адреса других ресурсов

Расширить список обхода можно через следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить. Например, если IP-сеть есть в `ipset-all.txt`, но конкретный домен из неё фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые следует исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
